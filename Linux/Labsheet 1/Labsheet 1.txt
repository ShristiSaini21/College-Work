#Q46
Explanation:
Running "rm -rf *" in an unverified path is hazardous because it recursively and forcibly deletes every
file and subdirectory in the current directory without asking for confirmation. If you are in the wrong
directory (e.g., "/" or your home directory instead of a temp folder), this command can permanently wipe
out critical system files or personal data with no warning and no way to undo it, since rm does not move
files to a trash/recycle bin.

Safety habit: Always run "pwd" first to confirm your current directory, and use "ls" to see exactly what
will be deleted before running any "rm -rf" command. It is also good practice to first run "rm -ri *"
(interactive mode) or do a dry run with "ls" matching the same pattern you intend to delete.
